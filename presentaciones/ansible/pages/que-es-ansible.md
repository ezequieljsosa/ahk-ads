<h2>¿Qué es Ansible?</h2>
<span class="gamma-badge badge-domain">Conceptos</span>
</div>

<div class="grid grid-cols-2 gap-4 my-auto">
<div class="gamma-card p-4">
<h3 class="text-sm font-bold text-cyan-300 mb-2">Definición</h3>
<p class="text-xs text-slate-300 mb-2">
Software <strong>open source</strong> para la gestión, configuración y despliegue automatizado de infraestructura.
</p>
<ul class="text-xs text-slate-300 space-y-2 list-disc list-inside">
<li><strong>Escalable:</strong> de 1 a miles de servidores con el mismo código.</li>
<li><strong>Simple:</strong> infraestructura como código en archivos YAML legibles.</li>
<li><strong>Sin agentes:</strong> solo necesita SSH; nada que instalar en las máquinas gestionadas.</li>
<li><strong>Declarativo:</strong> se describe el estado deseado, no los pasos.</li>
</ul>
</div>

<div class="gamma-card p-4">
<h3 class="text-sm font-bold text-purple-300 mb-2">¿Para qué sirve? Casos típicos</h3>
<ul class="text-xs text-slate-300 space-y-2 list-disc list-inside">
<li>Instalar y configurar un servidor web en 20 máquinas a la vez.</li>
<li>Crear usuarios y claves SSH de todo un equipo.</li>
<li>Aplicar parches de seguridad en una ventana de mantenimiento.</li>
<li>Armar un entorno de desarrollo idéntico al de producción.</li>
<li>Preparar nodos de un clúster (HPC, Kubernetes) de forma reproducible.</li>
</ul>
</div>
</div>

<div class="gamma-card p-3 text-center bg-indigo-950/30 text-xs text-slate-300">
⚡ <em>Ansible aplica archivos de configuración y tareas sobre uno o varios hosts hasta alcanzar el estado deseado.</em>
</div>
